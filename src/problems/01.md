## Shart

`F(0) = 0`, `F(1) = 1`, `F(n) = F(n-1) + F(n-2)`. Berilgan n uchun `F(n) mod 1 000 000 007` ni toping.

## Kirish va chiqish

Bitta son n (0 ≤ n ≤ 10^6). Bitta son — `F(n) mod 10^9+7`.

## Misollar

```input
10
```
```output
55
```
```input
50
```
```output
586268941
```

## Hintlar

- F(n) faqat oldingi ikki qiymatga bog'liq.
- `long` ham F(92) dan keyin to'lib ketadi — har qadamda `% MOD`.
- Massiv shart emas: ikkita o'zgaruvchi yetarli.

## G'oya

Bottom-up: `a = F(i)`, `b = F(i+1)` juftligini n marta siljitamiz. Bonus: n ≤ 10^18 bo'lsa — 2×2 matritsani darajaga ko'tarish, O(log n).

## Yechim

```java
import java.util.*;
import java.io.*;

public class Main {
    @IO

    public static void main(String[] args) throws IOException {
        int n = ni();
        long MOD = 1_000_000_007L;
        long a = 0, b = 1;
        for (int i = 0; i < n; i++) {
            long c = (a + b) % MOD;
            a = b;
            b = c;
        }
        System.out.println(a);
    }
}
```

## Murakkablik

Vaqt O(n), xotira O(1).

## Shart

Kubik 1 dan 6 gacha son chiqaradi. n sonini bir yoki bir necha marta kubik tashlab, chiqqan sonlar yig'indisi sifatida necha xil usulda hosil qilish mumkin? Tartib muhim: `1+2` va `2+1` — har xil. Javob mod 10^9+7.

## Kirish va chiqish

Bitta son n (1 ≤ n ≤ 10^6). Usullar soni mod 10^9+7.

## Misollar

```input
3
```
```output
4
```
```input
7
```
```output
63
```

## Hintlar

- Oxirgi tashlashda qaysi son chiqqan bo'lishi mumkin?
- `dp[s]` — yig'indi s ni hosil qilish usullari. Oxirgi son k bo'lsa, oldin `s-k` bo'lgan.
- `dp[0] = 1`.

## G'oya

`dp[s] = dp[s-1] + dp[s-2] + … + dp[s-6]` (manfiy indekslarsiz). Bu climbing stairs'ning 6 qadamli varianti.

## Yechim

```java
import java.util.*;
import java.io.*;

public class Main {
    @IO

    public static void main(String[] args) throws IOException {
        int n = ni();
        long MOD = 1_000_000_007L;
        long[] dp = new long[n + 1];
        dp[0] = 1;
        for (int s = 1; s <= n; s++) {
            for (int k = 1; k <= 6 && k <= s; k++) {
                dp[s] += dp[s - k];
            }
            dp[s] %= MOD;
        }
        System.out.println(dp[n]);
    }
}
```

## Murakkablik

Vaqt O(6n), xotira O(n).

## Shart

N ta tosh, i-toshning balandligi `h[i]`. Qurbaqa 1-toshda. i-toshdan i+1 yoki i+2-toshga sakraydi, xarajat `|h[i] - h[j]|`. N-toshga yetishning minimal umumiy xarajati?

## Kirish va chiqish

Birinchi qatorda N (2 ≤ N ≤ 10^5), ikkinchisida `h[1..N]` (1 ≤ h ≤ 10^4). Bitta son — minimal xarajat.

## Misollar

```input
4
10 30 40 20
```
```output
30
```
```input
2
10 10
```
```output
0
```
```input
6
30 10 60 10 60 50
```
```output
40
```

## Hintlar

- `dp[i]` — i-toshga yetishning minimal xarajati.
- i-toshga faqat ikki joydan kelish mumkin.
- `dp[0] = 0`; i = 1 uchun faqat bitta variant bor.

## G'oya

`dp[i] = min(dp[i-1] + |h[i]-h[i-1]|, dp[i-2] + |h[i]-h[i-2]|)`. Javob `dp[N-1]`.

## Yechim

```java
import java.util.*;
import java.io.*;

public class Main {
    @IO

    public static void main(String[] args) throws IOException {
        int n = ni();
        int[] h = new int[n];
        for (int i = 0; i < n; i++) h[i] = ni();
        int[] dp = new int[n];
        for (int i = 1; i < n; i++) {
            dp[i] = dp[i - 1] + Math.abs(h[i] - h[i - 1]);
            if (i >= 2) dp[i] = Math.min(dp[i], dp[i - 2] + Math.abs(h[i] - h[i - 2]));
        }
        System.out.println(dp[n - 1]);
    }
}
```

## Murakkablik

Vaqt O(N), xotira O(N).

## Shart

Qatorda n ta uy, i-uyda `a[i]` pul bor. Qo'shni ikki uydan birdaniga o'g'irlab bo'lmaydi. Maksimal qancha pul olish mumkin?

## Kirish va chiqish

n (1 ≤ n ≤ 10^5), keyin `a[1..n]` (0 ≤ a ≤ 10^4). Maksimal summa.

## Misollar

```input
4
1 2 3 1
```
```output
4
```
```input
5
2 7 9 3 1
```
```output
12
```

## Hintlar

- i-uy uchun faqat ikki tanlov bor: olish yoki olmaslik.
- Olsak, (i-1)-uy olinmagan bo'lishi kerak.
- `dp[i]` — dastlabki i ta uy uchun javob; `dp[0] = 0`, `dp[1] = a[0]`.

## G'oya

`dp[i] = max(dp[i-1], dp[i-2] + a[i-1])`.

## Yechim

```java
import java.util.*;
import java.io.*;

public class Main {
    @IO

    public static void main(String[] args) throws IOException {
        int n = ni();
        long[] a = new long[n];
        for (int i = 0; i < n; i++) a[i] = nl();
        long[] dp = new long[n + 1];
        dp[1] = a[0];
        for (int i = 2; i <= n; i++) {
            dp[i] = Math.max(dp[i - 1], dp[i - 2] + a[i - 1]);
        }
        System.out.println(dp[n]);
    }
}
```

## Murakkablik

Vaqt O(n), xotira O(n) (ikki o'zgaruvchi bilan O(1)).

## Shart

Harflar raqamlar bilan kodlangan: `A=1, B=2, …, Z=26`. Faqat raqamlardan iborat s satri berilgan. Uni harflarga necha xil usulda dekodlash mumkin? `06` kabi boshida nol bo'lgan kod yaroqsiz. Javob mod 10^9+7.

## Kirish va chiqish

Bitta satr s (1 ≤ |s| ≤ 10^5). Usullar soni mod 10^9+7.

## Misollar

```input
12
```
```output
2
```
```input
226
```
```output
3
```
```input
06
```
```output
0
```

## Hintlar

- Oxirgi harf bitta raqamdan yoki ikkita raqamdan iborat bo'lishi mumkin.
- Bitta raqam '0' bo'lsa — yaroqsiz.
- Ikki raqamli kod faqat 10..26 oralig'ida.

## G'oya

`dp[i]` — birinchi i ta belgini dekodlash usullari. `dp[0] = 1`. Ikki shartli had qo'shiladi.

## Yechim

```java
import java.util.*;
import java.io.*;

public class Main {
    @IO

    public static void main(String[] args) throws IOException {
        String s = next();
        int n = s.length();
        long MOD = 1_000_000_007L;
        long[] dp = new long[n + 1];
        dp[0] = 1;
        for (int i = 1; i <= n; i++) {
            if (s.charAt(i - 1) != '0') dp[i] += dp[i - 1];
            if (i >= 2) {
                int two = (s.charAt(i - 2) - '0') * 10 + (s.charAt(i - 1) - '0');
                if (two >= 10 && two <= 26) dp[i] += dp[i - 2];
            }
            dp[i] %= MOD;
        }
        System.out.println(dp[n]);
    }
}
```

## Murakkablik

Vaqt O(n), xotira O(n).

## Shart

n×n to'r: `.` — bo'sh katak, `*` — tuzoq. Chap-yuqori katakdan o'ng-pastki katakka faqat o'ngga va pastga yurib, tuzoqlarga tushmasdan nechta yo'l bor? Javob mod 10^9+7.

## Kirish va chiqish

n (1 ≤ n ≤ 1000), keyin n ta qator. Yo'llar soni.

## Misollar

```input
4
....
.*..
...*
*...
```
```output
3
```

## Hintlar

- Katakka faqat yuqoridan yoki chapdan kelinadi.
- Tuzoqli katakda yo'llar soni 0.
- Boshlang'ich katak tuzoq bo'lishi ham mumkin!

## G'oya

`dp[i][j] = dp[i-1][j] + dp[i][j-1]`, tuzoqda 0. Xotirani tejash uchun bitta qator.

## Yechim

```java
import java.util.*;
import java.io.*;

public class Main {
    @IO

    public static void main(String[] args) throws IOException {
        int n = ni();
        long MOD = 1_000_000_007L;
        long[] dp = new long[n];
        for (int i = 0; i < n; i++) {
            String row = next();
            for (int j = 0; j < n; j++) {
                if (row.charAt(j) == '*') dp[j] = 0;
                else if (i == 0 && j == 0) dp[j] = 1;
                else if (j > 0) dp[j] = (dp[j] + dp[j - 1]) % MOD;
            }
        }
        System.out.println(dp[n - 1]);
    }
}
```

## Murakkablik

Vaqt O(n²), xotira O(n).

## Shart

n×m jadval, har katakda manfiy bo'lmagan son. Chap-yuqoridan o'ng-pastga faqat o'ngga yoki pastga yurib, yo'ldagi sonlar yig'indisini minimal qiling.

## Kirish va chiqish

n m (1 ≤ n, m ≤ 1000), keyin jadval (0 ≤ a ≤ 100). Minimal yig'indi.

## Misollar

```input
3 3
1 3 1
1 5 1
4 2 1
```
```output
7
```
```input
2 3
1 2 3
4 5 6
```
```output
12
```

## Hintlar

- `dp[i][j]` — (i, j) ga yetishning minimal narxi (katakning o'zi bilan).
- Birinchi qator va ustunda tanlov yo'q.
- Yo'q qo'shni uchun `INF` ishlating.

## G'oya

`dp[i][j] = a[i][j] + min(dp[i-1][j], dp[i][j-1])`.

## Yechim

```java
import java.util.*;
import java.io.*;

public class Main {
    @IO

    public static void main(String[] args) throws IOException {
        int n = ni(), m = ni();
        long INF = Long.MAX_VALUE / 4;
        long[] dp = new long[m];
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                long x = nl();
                if (i == 0 && j == 0) { dp[j] = x; continue; }
                long up = i > 0 ? dp[j] : INF;
                long left = j > 0 ? dp[j - 1] : INF;
                dp[j] = x + Math.min(up, left);
            }
        }
        System.out.println(dp[m - 1]);
    }
}
```

Vaqt O(nm), xotira O(m).

## Shart

n uzunlikdagi massivning har elementi 1..m oralig'ida, qo'shni elementlar farqi ko'pi bilan 1. Ba'zi qiymatlar ma'lum, noma'lumlari 0 bilan berilgan. Shartlarga mos nechta massiv bor? Javob mod 10^9+7.

## Kirish va chiqish

n m (1 ≤ n ≤ 10^5, 1 ≤ m ≤ 100), keyin n ta son (0 ≤ x ≤ m). Massivlar soni.

## Misollar

```input
3 5
2 0 2
```
```output
3
```

## Hintlar

- Faqat pozitsiya emas, shu pozitsiyadagi qiymat ham muhim.
- `dp[i][v]` — i-pozitsiyada qiymat v bo'lgan to'g'ri prefikslar soni.
- Ma'lum pozitsiyada faqat bitta v ruxsat etiladi.

## G'oya

`dp[i][v] = dp[i-1][v-1] + dp[i-1][v] + dp[i-1][v+1]`. Massivni `m + 2` o'lchamda olsak, chegaralarni tekshirish shart emas.

## Yechim

```java
import java.util.*;
import java.io.*;

public class Main {
    @IO

    public static void main(String[] args) throws IOException {
        int n = ni(), m = ni();
        long MOD = 1_000_000_007L;
        int[] x = new int[n];
        for (int i = 0; i < n; i++) x[i] = ni();
        long[] dp = new long[m + 2];
        for (int v = 1; v <= m; v++) {
            if (x[0] == 0 || x[0] == v) dp[v] = 1;
        }
        for (int i = 1; i < n; i++) {
            long[] nd = new long[m + 2];
            for (int v = 1; v <= m; v++) {
                if (x[i] != 0 && x[i] != v) continue;
                nd[v] = (dp[v - 1] + dp[v] + dp[v + 1]) % MOD;
            }
            dp = nd;
        }
        long ans = 0;
        for (int v = 1; v <= m; v++) ans = (ans + dp[v]) % MOD;
        System.out.println(ans);
    }
}
```

## Murakkablik

Vaqt O(n·m), xotira O(m).
