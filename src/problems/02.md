## Shart

N ta buyum, i-buyum og'irligi `w[i]`, qiymati `v[i]`. Sumka ko'pi bilan W og'irlik ko'taradi. Har buyumni ko'pi bilan bir marta olib, maksimal umumiy qiymatni toping.

## Kirish va chiqish

N W (1 ≤ N ≤ 100, 1 ≤ W ≤ 10^5), keyin N qatorda `w v` (1 ≤ w ≤ W, 1 ≤ v ≤ 10^9). Maksimal qiymat.

## Misollar

```input
3 8
3 30
4 50
5 60
```
```output
90
```
```input
5 5
1 1000000000
1 1000000000
1 1000000000
1 1000000000
1 1000000000
```
```output
5000000000
```
```input
6 15
6 5
5 6
6 4
6 6
3 5
7 2
```
```output
17
```

## Hintlar

- Qiymatlar yig'indisi 10^11 gacha — `long` kerak.
- `dp[c]` — og'irligi ≤ c bo'lgan maksimal qiymat.
- Bir buyumni ikki marta olmaslik uchun c ni teskari aylaning.

## G'oya

Klassik 0/1 knapsack, 1D massiv va kamayuvchi tsikl: `dp[c] = max(dp[c], dp[c - w] + v)`.

## Yechim

```java
import java.util.*;
import java.io.*;

public class Main {
    @IO

    public static void main(String[] args) throws IOException {
        int n = ni(), W = ni();
        long[] dp = new long[W + 1];
        for (int i = 0; i < n; i++) {
            int w = ni();
            long v = nl();
            for (int c = W; c >= w; c--) {
                dp[c] = Math.max(dp[c], dp[c - w] + v);
            }
        }
        System.out.println(dp[W]);
    }
}
```

## Murakkablik

Vaqt O(N·W), xotira O(W).

## Shart

Do'konda n ta kitob: i-kitob narxi `h[i]`, sahifalari `s[i]`. Sizda x so'm bor. Har kitobni ko'pi bilan bir dona sotib olib, maksimal nechta sahifa yig'ish mumkin?

## Kirish va chiqish

n x (1 ≤ n ≤ 1000, 1 ≤ x ≤ 10^5), keyin n ta narx, keyin n ta sahifa soni. Maksimal sahifalar.

## Misollar

```input
4 10
4 8 5 3
5 12 8 1
```
```output
13
```

## Hintlar

- Bu aynan 0/1 knapsack: narx — og'irlik, sahifa — qiymat.
- 10^5 · 1000 = 10^8 amal — 1D massiv bilan Java'da o'tadi.
- 2D `int[1001][100001]` ~400 MB — sig'maydi.

## G'oya

1D knapsack, teskari tsikl.

## Yechim

```java
import java.util.*;
import java.io.*;

public class Main {
    @IO

    public static void main(String[] args) throws IOException {
        int n = ni(), x = ni();
        int[] h = new int[n], s = new int[n];
        for (int i = 0; i < n; i++) h[i] = ni();
        for (int i = 0; i < n; i++) s[i] = ni();
        int[] dp = new int[x + 1];
        for (int i = 0; i < n; i++) {
            for (int c = x; c >= h[i]; c--) {
                dp[c] = Math.max(dp[c], dp[c - h[i]] + s[i]);
            }
        }
        System.out.println(dp[x]);
    }
}
```

## Murakkablik

Vaqt O(n·x), xotira O(x).

## Shart

Knapsack 1 bilan bir xil, lekin W ≤ 10^9, `v[i]` ≤ 1000, N ≤ 100.

## Kirish va chiqish

N W, keyin N qatorda `w v` (1 ≤ w ≤ W ≤ 10^9, 1 ≤ v ≤ 10^3). Maksimal qiymat.

## Misollar

```input
3 8
3 30
4 50
5 60
```
```output
90
```
```input
1 1000000000
1000000000 10
```
```output
10
```
```input
6 15
6 5
5 6
6 4
6 6
3 5
7 2
```
```output
17
```

## Hintlar

- `dp[W]` massivi 10^9 o'lchamda bo'la olmaydi.
- Umumiy qiymat ko'pi bilan 100·1000 = 10^5.
- `dp[val]` — aynan val qiymat uchun minimal og'irlik.

## G'oya

Indeks va qiymat o'rnini almashtiramiz. Javob — `dp[val] ≤ W` bo'lgan eng katta val.

## Yechim

```java
import java.util.*;
import java.io.*;

public class Main {
    @IO

    public static void main(String[] args) throws IOException {
        int n = ni();
        long W = nl();
        int maxV = 100_000;
        long INF = Long.MAX_VALUE / 4;
        long[] dp = new long[maxV + 1];
        Arrays.fill(dp, INF);
        dp[0] = 0;
        for (int i = 0; i < n; i++) {
            long w = nl();
            int v = ni();
            for (int val = maxV; val >= v; val--) {
                if (dp[val - v] + w < dp[val]) dp[val] = dp[val - v] + w;
            }
        }
        int ans = 0;
        for (int val = 0; val <= maxV; val++) {
            if (dp[val] <= W) ans = val;
        }
        System.out.println(ans);
    }
}
```

## Murakkablik

Vaqt O(N·ΣV), xotira O(ΣV).

## Shart

n ta musbat sonni yig'indilari teng ikki guruhga bo'lish mumkinmi?

## Kirish va chiqish

n (1 ≤ n ≤ 200), keyin n ta son (1 ≤ a ≤ 100). `YES` yoki `NO`.

## Misollar

```input
4
1 5 11 5
```
```output
YES
```
```input
4
1 2 3 5
```
```output
NO
```

## Hintlar

- Umumiy yig'indi toq bo'lsa, javob darhol `NO`.
- Bitta guruh yig'indisi aynan `T/2` bo'lishi kerak.
- Subset sum: `can[s]` — yig'indi s ni hosil qilsa bo'ladimi.

## G'oya

`boolean` knapsack, teskari tsikl. Javob `can[T/2]`.

## Yechim

```java
import java.util.*;
import java.io.*;

public class Main {
    @IO

    public static void main(String[] args) throws IOException {
        int n = ni();
        int[] a = new int[n];
        int total = 0;
        for (int i = 0; i < n; i++) {
            a[i] = ni();
            total += a[i];
        }
        if (total % 2 == 1) {
            System.out.println("NO");
            return;
        }
        int half = total / 2;
        boolean[] can = new boolean[half + 1];
        can[0] = true;
        for (int x : a) {
            for (int s = half; s >= x; s--) {
                if (can[s - x]) can[s] = true;
            }
        }
        System.out.println(can[half] ? "YES" : "NO");
    }
}
```

## Murakkablik

Vaqt O(n·T), xotira O(T).

## Shart

n xil tanga (har biridan cheksiz). x summani minimal nechta tanga bilan yig'ish mumkin? Imkonsiz bo'lsa `-1`.

## Kirish va chiqish

n x (1 ≤ n ≤ 100, 1 ≤ x ≤ 10^6), keyin n ta tanga qiymati (1 ≤ c ≤ 10^6). Minimal tangalar soni yoki -1.

## Misollar

```input
3 11
1 5 7
```
```output
3
```
```input
1 3
2
```
```output
-1
```

## Hintlar

- Greedy ishlamaydi — {1, 5, 7} va 10: greedy 7+1+1+1 = 4, to'g'risi 5+5 = 2.
- `dp[s]` — s uchun minimal tangalar. Oxirgi tanga c bo'lsa, oldin `s - c` bo'lgan.
- `INF` ni `MAX_VALUE / 2` qiling.

## G'oya

`dp[s] = min(dp[s - c] + 1)`. 10^6 · 100 = 10^8 — oddiy tsikl bilan o'tadi.

## Yechim

```java
import java.util.*;
import java.io.*;

public class Main {
    @IO

    public static void main(String[] args) throws IOException {
        int n = ni(), x = ni();
        int[] coins = new int[n];
        for (int i = 0; i < n; i++) coins[i] = ni();
        int INF = Integer.MAX_VALUE / 2;
        int[] dp = new int[x + 1];
        Arrays.fill(dp, INF);
        dp[0] = 0;
        for (int s = 1; s <= x; s++) {
            for (int c : coins) {
                if (c <= s && dp[s - c] + 1 < dp[s]) dp[s] = dp[s - c] + 1;
            }
        }
        System.out.println(dp[x] >= INF ? -1 : dp[x]);
    }
}
```

## Murakkablik

Vaqt O(n·x), xotira O(x).

## Shart

n xil tanga. x summani hosil qilishning **tartibli bo'lmagan** usullari soni (2+3 va 3+2 — bitta usul). Javob mod 10^9+7.

## Kirish va chiqish

n x (1 ≤ n ≤ 100, 1 ≤ x ≤ 10^6), keyin n ta tanga. Usullar soni.

## Misollar

```input
3 9
2 3 5
```
```output
3
```

## Hintlar

- Coin Combinations I (tartib muhim) da xuddi shu input uchun javob 8 bo'lardi.
- Farq faqat tsikllar tartibida.
- Tashqi tsikl — tangalar, ichki — summa.

## G'oya

Tangalarni birma-bir "ochamiz": `dp[s] += dp[s - c]`. Shunda har bir to'plam faqat tangalar tartibida sanaladi.

## Yechim

```java
import java.util.*;
import java.io.*;

public class Main {
    @IO

    public static void main(String[] args) throws IOException {
        int n = ni(), x = ni();
        int MOD = 1_000_000_007;
        int[] dp = new int[x + 1];
        dp[0] = 1;
        for (int i = 0; i < n; i++) {
            int c = ni();
            for (int s = c; s <= x; s++) {
                dp[s] += dp[s - c];
                if (dp[s] >= MOD) dp[s] -= MOD;
            }
        }
        System.out.println(dp[x]);
    }
}
```

## Murakkablik

Vaqt O(n·x), xotira O(x). `% MOD` o'rniga ayirish — bir oz tezroq.

## Shart

n ta sondan iborat massivning eng uzun qat'iy o'suvchi subsequence uzunligini toping.

## Kirish va chiqish

n (1 ≤ n ≤ 2·10^5), keyin n ta son (1 ≤ x ≤ 10^9). LIS uzunligi.

## Misollar

```input
8
7 3 5 3 6 2 9 8
```
```output
4
```

## Hintlar

- n = 2·10^5 da O(n²) juda sekin.
- `tails[k]` — uzunligi k+1 bo'lgan o'suvchi ketma-ketlikning eng kichik oxiri.
- Qat'iy o'sish uchun lower bound (`>= x` birinchi element).

## G'oya

Har bir x uchun `tails` ichida binary search qilib, uni almashtiramiz yoki oxiriga qo'shamiz.

## Yechim

```java
import java.util.*;
import java.io.*;

public class Main {
    @IO

    public static void main(String[] args) throws IOException {
        int n = ni();
        int[] tails = new int[n];
        int len = 0;
        for (int i = 0; i < n; i++) {
            int x = ni();
            int lo = 0, hi = len;
            while (lo < hi) {
                int mid = (lo + hi) >>> 1;
                if (tails[mid] < x) lo = mid + 1;
                else hi = mid;
            }
            tails[lo] = x;
            if (lo == len) len++;
        }
        System.out.println(len);
    }
}
```

## Murakkablik

Vaqt O(n log n), xotira O(n).
