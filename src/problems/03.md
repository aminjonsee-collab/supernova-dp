## Shart

Ikki satr s va t berilgan. Ularning eng uzun umumiy subsequence'ini (o'zini, uzunligini emas) chiqaring. Bir nechta javob bo'lsa — istalganini.

## Kirish va chiqish

Ikki qatorda s va t (1 ≤ |s|, |t| ≤ 3000, kichik lotin harflari). Bitta LCS satri (bo'sh bo'lishi mumkin).

## Misollar

```input
axyb
abyxb
```
```output
axb
```
```input
aa
xayaaxa
```
```output
aa
```
```input
abracadabra
avadakedavra
```
```output
aaadara
```

## Hintlar

- Avval odatdagi LCS uzunlik jadvalini to'ldiring.
- (n, m) dan orqaga yuring: belgilar teng bo'lsa — javobga qo'shib, diagonal bo'ylab.
- Aks holda kattaroq qo'shni tomon yuring. Oxirida satrni teskari aylantiring.

## G'oya

`dp[i][j]` — prefikslar LCS uzunligi. Traceback `StringBuilder` bilan.

## Yechim

```java
import java.util.*;
import java.io.*;

public class Main {
    @IO

    public static void main(String[] args) throws IOException {
        String s = next(), t = next();
        int n = s.length(), m = t.length();
        int[][] dp = new int[n + 1][m + 1];
        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= m; j++) {
                if (s.charAt(i - 1) == t.charAt(j - 1)) dp[i][j] = dp[i - 1][j - 1] + 1;
                else dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
            }
        }
        StringBuilder sb = new StringBuilder();
        int i = n, j = m;
        while (i > 0 && j > 0) {
            if (s.charAt(i - 1) == t.charAt(j - 1)) {
                sb.append(s.charAt(i - 1));
                i--;
                j--;
            } else if (dp[i - 1][j] >= dp[i][j - 1]) i--;
            else j--;
        }
        System.out.println(sb.reverse());
    }
}
```

## Murakkablik

Vaqt O(nm), xotira O(nm) — 3001² `int` ≈ 36 MB.

## Shart

Bitta amalda satrga belgi qo'shish, o'chirish yoki bitta belgini almashtirish mumkin. Birinchi satrni ikkinchisiga aylantirish uchun minimal nechta amal kerak?

## Kirish va chiqish

Ikki qatorda satrlar (1 ≤ uzunlik ≤ 5000, katta lotin harflari). Minimal amallar soni.

## Misollar

```input
LOVE
MOVIE
```
```output
2
```

## Hintlar

- `dp[i][j]` — s ning i-prefiksini t ning j-prefiksiga aylantirish narxi.
- `dp[i][0] = i`, `dp[0][j] = j`.
- 5001² `int` = 100 MB — ikkita qator yetarli.

## G'oya

Belgilar teng bo'lsa — diagonal; aks holda `1 + min(chap, yuqori, diagonal)`.

## Yechim

```java
import java.util.*;
import java.io.*;

public class Main {
    @IO

    public static void main(String[] args) throws IOException {
        String s = next(), t = next();
        int n = s.length(), m = t.length();
        int[] prev = new int[m + 1], cur = new int[m + 1];
        for (int j = 0; j <= m; j++) prev[j] = j;
        for (int i = 1; i <= n; i++) {
            cur[0] = i;
            char c = s.charAt(i - 1);
            for (int j = 1; j <= m; j++) {
                if (c == t.charAt(j - 1)) cur[j] = prev[j - 1];
                else cur[j] = 1 + Math.min(prev[j - 1], Math.min(prev[j], cur[j - 1]));
            }
            int[] tmp = prev;
            prev = cur;
            cur = tmp;
        }
        System.out.println(prev[m]);
    }
}
```

## Murakkablik

Vaqt O(nm), xotira O(m).

## Shart

s satri va k ta so'zdan iborat lug'at berilgan. s ni lug'at so'zlariga (so'zlar takrorlanishi mumkin) bo'lib bo'ladimi?

## Kirish va chiqish

Birinchi qatorda s (|s| ≤ 10^4), ikkinchisida k (k ≤ 1000), keyin k ta so'z (har biri ≤ 20 belgi). `YES` yoki `NO`.

## Misollar

```input
leetcode
2
leet code
```
```output
YES
```
```input
applepenapple
2
apple pen
```
```output
YES
```
```input
catsandog
5
cats dog sand and cat
```
```output
NO
```

## Hintlar

- `ok[i]` — s ning birinchi i ta belgisini bo'lsa bo'ladimi.
- Oxirgi so'z `s[j..i)` bo'lsa, `ok[j]` true bo'lishi kerak.
- So'z uzunligi ≤ 20 — j ni faqat shu masofada tekshiring.

## G'oya

`HashSet` + prefiks DP. Har i uchun ko'pi bilan 20 ta substring tekshiriladi.

## Yechim

```java
import java.util.*;
import java.io.*;

public class Main {
    @IO

    public static void main(String[] args) throws IOException {
        String s = next();
        int k = ni();
        Set<String> dict = new HashSet<>();
        int maxLen = 0;
        for (int i = 0; i < k; i++) {
            String w = next();
            dict.add(w);
            maxLen = Math.max(maxLen, w.length());
        }
        int n = s.length();
        boolean[] ok = new boolean[n + 1];
        ok[0] = true;
        for (int i = 1; i <= n; i++) {
            for (int len = 1; len <= Math.min(i, maxLen) && !ok[i]; len++) {
                if (ok[i - len] && dict.contains(s.substring(i - len, i))) ok[i] = true;
            }
        }
        System.out.println(ok[n] ? "YES" : "NO");
    }
}
```

## Murakkablik

Vaqt O(n · L²) (L — maksimal so'z uzunligi, substring narxi bilan), xotira O(n).

## Shart

s satrini har bir bo'lagi palindrom bo'ladigan qilib bo'laklarga ajrating. Minimal nechta kesish kerak?

## Kirish va chiqish

Bitta satr s (1 ≤ |s| ≤ 2000). Minimal kesishlar soni.

## Misollar

```input
aab
```
```output
1
```
```input
a
```
```output
0
```
```input
ab
```
```output
1
```

## Hintlar

- Ikki bosqich: avval qaysi `s[l..r]` palindrom ekanini hisoblang.
- `cut[i]` — `s[0..i]` prefiksi uchun minimal kesish.
- Oxirgi bo'lak `s[j..i]` palindrom bo'lsa: `cut[j-1] + 1`.

## G'oya

`pal[l][r]` jadvali O(n²), keyin `cut` ham O(n²).

## Yechim

```java
import java.util.*;
import java.io.*;

public class Main {
    @IO

    public static void main(String[] args) throws IOException {
        String s = next();
        int n = s.length();
        boolean[][] pal = new boolean[n][n];
        for (int l = n - 1; l >= 0; l--) {
            for (int r = l; r < n; r++) {
                pal[l][r] = s.charAt(l) == s.charAt(r) && (r - l < 2 || pal[l + 1][r - 1]);
            }
        }
        int[] cut = new int[n];
        for (int i = 0; i < n; i++) {
            if (pal[0][i]) { cut[i] = 0; continue; }
            cut[i] = i;
            for (int j = 1; j <= i; j++) {
                if (pal[j][i]) cut[i] = Math.min(cut[i], cut[j - 1] + 1);
            }
        }
        System.out.println(cut[n - 1]);
    }
}
```

## Murakkablik

Vaqt O(n²), xotira O(n²).

## Shart

Qatorda N ta slime, o'lchamlari `a[i]`. Har safar ikki qo'shni slime birlashadi; xarajat — ular o'lchamlari yig'indisi, yangi slime o'lchami ham shu yig'indi. Hammasini bitta slime qilishning minimal umumiy xarajati?

## Misollar

```input
4
10 20 30 40
```
```output
190
```
```input
5
10 10 10 10 10
```
```output
120
```
```input
3
1000000000 1000000000 1000000000
```
```output
5000000000
```
```input
6
7 6 8 6 1 1
```
```output
68
```

## Hintlar

- `[l, r]` oraliq bitta slime bo'lishidan oldingi oxirgi qadamda u ikki qismdan iborat bo'lgan.
- Oxirgi birlashtirish narxi doim `sum(l..r)` — bo'lish nuqtasidan qat'i nazar.
- Oraliqlarni uzunligi bo'yicha hisoblang.

## G'oya

`dp[l][r] = min_k (dp[l][k] + dp[k+1][r]) + sum(l, r)`, prefix sum bilan.

## Yechim

```java
import java.util.*;
import java.io.*;

public class Main {
    @IO

    public static void main(String[] args) throws IOException {
        int n = ni();
        long[] pre = new long[n + 1];
        for (int i = 0; i < n; i++) pre[i + 1] = pre[i] + nl();
        long[][] dp = new long[n][n];
        for (int len = 2; len <= n; len++) {
            for (int l = 0; l + len - 1 < n; l++) {
                int r = l + len - 1;
                long best = Long.MAX_VALUE;
                for (int k = l; k < r; k++) {
                    best = Math.min(best, dp[l][k] + dp[k + 1][r]);
                }
                dp[l][r] = best + pre[r + 1] - pre[l];
            }
        }
        System.out.println(dp[0][n - 1]);
    }
}
```

## Murakkablik

Vaqt O(N³) ≈ 6.4·10^7 / 6 amal, xotira O(N²).

## Shart

Massivda n ta son. Ikki o'yinchi navbat bilan chap yoki o'ng chetdagi sonni olib, o'z hisobiga qo'shadi. Ikkalasi ham o'z hisobini maksimallashtirishga intiladi. Birinchi o'yinchining maksimal ochkosi?

## Kirish va chiqish

n (1 ≤ n ≤ 5000), keyin n ta son (-10^9 ≤ x ≤ 10^9). Birinchi o'yinchi ochkosi.

## Misollar

```input
4
4 5 1 3
```
```output
8
```

## Hintlar

- Kimning navbati ekanini state'ga qo'shmasdan ham bo'ladi.
- `dp[l][r]` — navbatdagi o'yinchining raqibidan maksimal ustunligi (farq).
- Javob: `(sum + dp[0][n-1]) / 2`.

## G'oya

`dp[l][r] = max(a[l] - dp[l+1][r], a[r] - dp[l][r-1])`. l kamayish, r o'sish tartibida bitta 1D massiv yetarli: `d[r]` eski qiymati — `dp[l+1][r]`, `d[r-1]` yangisi — `dp[l][r-1]`.

## Yechim

```java
import java.util.*;
import java.io.*;

public class Main {
    @IO

    public static void main(String[] args) throws IOException {
        int n = ni();
        long[] a = new long[n];
        long sum = 0;
        for (int i = 0; i < n; i++) {
            a[i] = nl();
            sum += a[i];
        }
        long[] d = new long[n];
        for (int l = n - 1; l >= 0; l--) {
            d[l] = a[l];
            for (int r = l + 1; r < n; r++) {
                d[r] = Math.max(a[l] - d[r], a[r] - d[r - 1]);
            }
        }
        System.out.println((sum + d[n - 1]) / 2);
    }
}
```

## Murakkablik

Vaqt O(n²), xotira O(n).


## Hintlar

- `dp[i]` yetarli emas — kechagi faoliyat ham muhim.
- `dp[i][k]` — i-kun k-faoliyat bilan tugagan maksimal baxt.
- Bugungi k uchun kechagi p ≠ k.

## G'oya

## Yechim

```java
import java.util.*;
import java.io.*;

public class Main {
    @IO

    public static void main(String[] args) throws IOException {
        int n = ni();
        long[] dp = new long[3];
        for (int i = 0; i < n; i++) {
            long[] h = {nl(), nl(), nl()};
            long[] nd = new long[3];
            for (int k = 0; k < 3; k++) {
                long best = 0;
                for (int p = 0; p < 3; p++) {
                    if (p != k) best = Math.max(best, dp[p]);
                }
                nd[k] = best + h[k];
            }
            dp = nd;
        }
        System.out.println(Math.max(dp[0], Math.max(dp[1], dp[2])));
    }
}
```

## Shart

n kunlik aksiya narxlari berilgan. Istalgancha tranzaksiya qilish mumkin, lekin bir vaqtda ko'pi bilan bitta aksiya ushlaysiz va sotgandan keyingi kuni sotib ololmaysiz. Maksimal foyda?

## Kirish va chiqish

n (1 ≤ n ≤ 10^5), keyin n ta narx (0 ≤ p ≤ 10^4). Maksimal foyda.

## Misollar

```input
5
1 2 3 0 2
```
```output
3
```
```input
1
1
```
```output
0
```

## Hintlar

- Uchta holat: aksiya bor (`hold`), bugun sotildi (`sold`), bo'sh (`rest`).
- `sold` dan faqat `rest` ga o'tiladi — bu cooldown.
- Yangilashda kechagi qiymatlarni saqlab qo'ying.

## G'oya

`hold = max(hold, rest - p)`, `sold = hold + p`, `rest = max(rest, sold)` — hammasi kechagi qiymatlardan.

## Yechim

```java
import java.util.*;
import java.io.*;

public class Main {
    @IO

    public static void main(String[] args) throws IOException {
        int n = ni();
        long hold = Long.MIN_VALUE / 2, sold = 0, rest = 0;
        for (int i = 0; i < n; i++) {
            long p = nl();
            long pHold = hold, pSold = sold, pRest = rest;
            hold = Math.max(pHold, pRest - p);
            sold = pHold + p;
            rest = Math.max(pRest, pSold);
        }
        System.out.println(Math.max(sold, rest));
    }
}
```

## Murakkablik

Vaqt O(n), xotira O(1).
