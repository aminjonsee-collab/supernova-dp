## Shart

N ta tanga (N toq). i-tanga tashlanganda gerb tushish ehtimoli `p[i]`. Hammasi bir marta tashlanadi. Gerblar soni raqamlardan (yozuvlardan) ko'p bo'lish ehtimoli?

## Kirish va chiqish

N (1 ≤ N ≤ 2999, toq), keyin N ta haqiqiy son `p[i]` (0 < p < 1, ikki xona aniqlikda). Ehtimollik, xatolik ≤ 10^-9.

## Misollar

```input
3
0.30 0.60 0.80
```
```output
0.612
```
```input
1
0.50
```
```output
0.5
```
```input
5
0.42 0.01 0.42 0.99 0.42
```
```output
0.3821815872
```

## Hintlar

- `dp[i][j]` — birinchi i ta tangadan aynan j ta gerb tushish ehtimoli.
- i-tanga gerb yoki yozuv: ikki had.
- Javob — `j > N/2` bo'lgan `dp[N][j]` lar yig'indisi. Chiqarishda `Locale.US`!

## G'oya

0/1 knapsack'ka o'xshash 1D massiv, j kamayish tartibida. O(N²) ≈ 9·10^6.

## Yechim

```java
import java.util.*;
import java.io.*;

public class Main {
    @IO

    public static void main(String[] args) throws IOException {
        int n = ni();
        double[] p = new double[n];
        for (int i = 0; i < n; i++) p[i] = Double.parseDouble(next());
        double[] dp = new double[n + 1];
        dp[0] = 1;
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j >= 1; j--) {
                dp[j] = dp[j] * (1 - p[i]) + dp[j - 1] * p[i];
            }
            dp[0] *= 1 - p[i];
        }
        double ans = 0;
        for (int j = n / 2 + 1; j <= n; j++) ans += dp[j];
        System.out.println(String.format(Locale.US, "%.10f", ans));
    }
}
```

## Murakkablik

Vaqt O(N²), xotira O(N).

## Shart

N ta tarelka, i-tarelkada `a[i]` ta sushi (1 ≤ a ≤ 3). Har qadamda tasodifiy (teng ehtimol bilan) tarelka tanlanadi; unda sushi bo'lsa, bittasi yeyiladi. Hamma sushi tugaguncha kutilgan qadamlar soni?

## Kirish va chiqish

N (1 ≤ N ≤ 300), keyin `a[1..N]`. Kutilgan qadamlar soni, xatolik ≤ 10^-9.

## Misollar

```input
3
1 1 1
```
```output
5.5
```
```input
1
3
```
```output
3
```
```input
2
1 2
```
```output
4.5
```
```input
10
1 3 2 3 3 2 3 2 1 3
```
```output
54.48064457488221
```

## Hintlar

- Tarelkalar tartibi muhim emas — faqat nechta tarelkada 1, 2, 3 ta sushi borligi.
- State `(a, b, c)`; bo'sh tarelka tanlansa holat o'zgarmaydi — tenglamadan E ni ifodalang.
- `E(a,b,c) = (N + a·E(a-1,b,c) + b·E(a+1,b-1,c) + c·E(a,b+1,c-1)) / (a+b+c)`.

## G'oya

c → b → a o'sish tartibida uch qavat tsikl. `double[N+1][N+1][N+1]` ≈ 220 MB — AtCoder'da 1024 MB limit bor.

## Yechim

```java
import java.util.*;
import java.io.*;

public class Main {
    @IO

    public static void main(String[] args) throws IOException {
        int n = ni();
        int[] cnt = new int[4];
        for (int i = 0; i < n; i++) cnt[ni()]++;
        double[][][] E = new double[n + 1][n + 1][n + 1];
        for (int c = 0; c <= n; c++) {
            for (int b = 0; b + c <= n; b++) {
                for (int a = 0; a + b + c <= n; a++) {
                    if (a + b + c == 0) continue;
                    double s = n;
                    if (a > 0) s += a * E[a - 1][b][c];
                    if (b > 0) s += b * E[a + 1][b - 1][c];
                    if (c > 0) s += c * E[a][b + 1][c - 1];
                    E[a][b][c] = s / (a + b + c);
                }
            }
        }
        System.out.println(String.format(Locale.US, "%.10f", E[cnt[1]][cnt[2]][cnt[3]]));
    }
}
```

## Murakkablik

Vaqt O(N³/6), xotira O(N³).

## Shart

N ta bola, K ta konfet. i-bolaga 0 dan `a[i]` tagacha konfet berish mumkin. Barcha K konfetni qoldiqsiz taqsimlash usullari soni (mod 10^9+7)?

## Kirish va chiqish

N K (1 ≤ N ≤ 100, 0 ≤ K ≤ 10^5), keyin `a[1..N]` (0 ≤ a ≤ K). Usullar soni.

## Misollar

```input
3 4
1 2 3
```
```output
5
```
```input
1 10
9
```
```output
0
```
```input
2 0
0 0
```
```output
1
```
```input
4 100000
100000 100000 100000 100000
```
```output
665683269
```

## Hintlar

- `dp[i][j]` — birinchi i bolaga jami j konfet berish usullari.
- To'g'ridan-to'g'ri O(N·K²) — 10^12, juda sekin.
- `dp[i][j]` — `dp[i-1]` ning `[j - a[i], j]` oraliqdagi yig'indisi.

## G'oya

Har qatlamda prefix sum: `dp[j] = pre[j+1] - pre[max(0, j - a[i])]`.

## Yechim

```java
import java.util.*;
import java.io.*;

public class Main {
    @IO

    public static void main(String[] args) throws IOException {
        int n = ni(), K = ni();
        long MOD = 1_000_000_007L;
        long[] dp = new long[K + 1];
        dp[0] = 1;
        long[] pre = new long[K + 2];
        for (int i = 0; i < n; i++) {
            int a = ni();
            for (int j = 0; j <= K; j++) pre[j + 1] = (pre[j] + dp[j]) % MOD;
            for (int j = 0; j <= K; j++) {
                int lo = Math.max(0, j - a);
                dp[j] = (pre[j + 1] - pre[lo] + MOD) % MOD;
            }
        }
        System.out.println(dp[K]);
    }
}
```

## Murakkablik

Vaqt O(N·K), xotira O(K).

## Shart

N ta tosh, balandliklari qat'iy o'suvchi: `h[1] < h[2] < … < h[N]`. Qurbaqa i-toshdan istalgan j > i toshga sakraydi, xarajat `(h[j] - h[i])² + C`. N-toshga minimal xarajat?

## Kirish va chiqish

N C (2 ≤ N ≤ 2·10^5, 1 ≤ C ≤ 10^12), keyin `h[1..N]` (1 ≤ h ≤ 10^6). Minimal xarajat.

## Misollar

```input
5 6
1 2 3 4 5
```
```output
20
```
```input
2 1000000000000
500000 1000000
```
```output
1250000000000
```
```input
8 5
1 3 4 5 10 11 12 13
```
```output
62
```

## Hintlar

- O(N²) DP aniq, lekin 4·10^10 — juda sekin.
- Kvadratni oching: `h[j]² + C` va `min(-2h[i]·h[j] + dp[i] + h[i]²)`.
- Minimum ichidagi ifoda — x = h[j] nuqtadagi to'g'ri chiziq qiymati.

## G'oya

Li Chao tree [0, 10^6] oralig'ida: har i dan keyin `(m = -2h[i], b = dp[i] + h[i]²)` chizig'ini qo'shamiz, `dp[j]` uchun x = h[j] da minimumni so'raymiz.

## Yechim

```java
import java.util.*;
import java.io.*;

public class Main {
    @IO

    static long[] M, B;
    static boolean[] has;

    static long f(int node, long x) { return M[node] * x + B[node]; }

    static void add(int node, int lo, int hi, long m, long b) {
        if (!has[node]) { M[node] = m; B[node] = b; has[node] = true; return; }
        int mid = (lo + hi) >>> 1;
        boolean leftBetter = m * lo + b < f(node, lo);
        boolean midBetter = m * mid + b < f(node, mid);
        if (midBetter) {
            long tm = M[node], tb = B[node];
            M[node] = m;
            B[node] = b;
            m = tm;
            b = tb;
        }
        if (lo == hi) return;
        if (leftBetter != midBetter) add(2 * node, lo, mid, m, b);
        else add(2 * node + 1, mid + 1, hi, m, b);
    }

    static long query(int node, int lo, int hi, long x) {
        if (!has[node]) return Long.MAX_VALUE;
        long res = f(node, x);
        if (lo == hi) return res;
        int mid = (lo + hi) >>> 1;
        if (x <= mid) return Math.min(res, query(2 * node, lo, mid, x));
        return Math.min(res, query(2 * node + 1, mid + 1, hi, x));
    }

    public static void main(String[] args) throws IOException {
        int n = ni();
        long C = nl();
        long[] h = new long[n];
        for (int i = 0; i < n; i++) h[i] = nl();
        int X = 1_000_000;
        M = new long[4 * X + 4];
        B = new long[4 * X + 4];
        has = new boolean[4 * X + 4];
        long[] dp = new long[n];
        add(1, 0, X, -2 * h[0], h[0] * h[0]);
        for (int j = 1; j < n; j++) {
            dp[j] = query(1, 0, X, h[j]) + h[j] * h[j] + C;
            add(1, 0, X, -2 * h[j], dp[j] + h[j] * h[j]);
        }
        System.out.println(dp[n - 1]);
    }
}
```

## Murakkablik

Vaqt O(N log X), xotira O(X).
